# Інструкція з використання

## Передумови

- Встановлено VS Code.
- Доступний GitHub Copilot і Copilot Chat.
- Встановлено Git.
- Встановлено Python 3; команда `python` (Windows) або `python3` (Linux/macOS) доступна в `PATH`.
- Для локального CI на Linux/macOS встановлено Bash.

## Запуск агента

1. Відкрийте репозиторій у VS Code.
2. Створіть feature-гілку `feature/hello-python` і переконайтеся, що поточна гілка не `master` та не `develop`.
3. У Copilot Chat увімкніть режим **Agent** і виберіть `build-engineer`.
4. Виконайте `/init`. Команда послідовно запускає підготовку Git, структури проєкту, збірки, GitHub Actions і фінальну перевірку.
5. Після завершення за потреби окремо виконайте `/check`, щоб повторити перевірки.

## Локальна перевірка

Запустіть CI-скрипт для своєї операційної системи з кореня репозиторію:

- Linux/macOS: `bash ci.sh`
- Windows: `ci.bat`

Скрипт створює або використовує `.venv`, встановлює залежності, запускає `pytest` і збирає застосунок у `dist/`. Успішна перевірка включає тест `test_BasicAddition` і запуск зібраного Hello World.

## Запуск застосунку

- Із вихідного коду: `bash run.sh` на Linux/macOS або `run.bat` у Windows.
- Після CI-збирання: `dist/hello` на Linux/macOS або `dist\hello.exe` у Windows.

## Типові помилки

| Помилка | Що перевірити |
|---|---|
| `python` або `python3` не знайдено | Встановіть Python 3 і додайте його до `PATH`; відкрийте новий термінал і перевірте команду ще раз |
| `bash ci.sh` не запускається на Linux/macOS | Запускайте саме через `bash`; перевірте переноси рядків і правило `*.sh text eol=lf` у `.gitattributes` |
| Windows CI продовжується після помилки pytest | Перевірте, що після кожної команди в `ci.bat` є `if errorlevel 1 exit /b 1` |
| Не створюється `dist/hello` або `dist\hello.exe` | Перегляньте першу помилку PyInstaller у виводі CI та переконайтеся, що залежності встановлено у `.venv` |
| YAML workflow не розбирається | Перевірте відступи, структуру workflow та безпечно розберіть YAML, наприклад через `yaml.safe_load` |
| `/init` зупиняється через гілку | Перейдіть на feature-гілку; `/init` не виконується на `master` або `develop` |
| Залежності не встановлюються | Перевірте доступ до індексу пакетів і версію Python; не ігноруйте ненульовий код завершення |
