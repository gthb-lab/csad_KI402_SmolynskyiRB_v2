## Короткий опис

Проєкт демонструє використання агента GitHub Copilot у VS Code для створення, тестування та складання кросплатформного Python-застосунку Hello World. Агент `build-engineer` координує спеціалізовані prompt-команди та skills, а CI-скрипти перевіряють тести й створюють виконуваний файл за допомогою PyInstaller.

## Як запустити агента

1. Відкрийте репозиторій у VS Code.
2. Відкрийте Copilot Chat і виберіть режим **Agent**.
3. Виберіть агента `build-engineer`.
4. Створіть гілку `feature/hello-python`.
5. Виконайте команду `/init`.
6. Після завершення виконайте `/check`.

## Як запустити зібраний проєкт

- Для запуску з вихідного коду: `bash run.sh` у Linux/macOS або `run.bat` у Windows.
- Після успішного CI-збирання виконайте `dist/hello` у Linux/macOS або `dist\hello.exe` у Windows.

## Структура репозиторію

```text
.github/
  agents/       Маніфести спеціалізованих агентів
  prompts/      Команди для окремих етапів і їх оркестрації
  skills/       Інструкції для створення проєкту, збірки та GitHub Actions
  workflows/    Конфігурація CI для GitHub Actions
src/            Вихідний код застосунку
tests/          Автоматизовані тести pytest
docs/           Архітектура, інструкції та журнал взаємодії з AI
```
